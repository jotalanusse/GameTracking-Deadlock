# GameTracking-Deadlock (mirror)

A fork of [SteamTracking/GameTracking-Deadlock](https://github.com/SteamTracking/GameTracking-Deadlock), kept as a backup copy for [soular](https://github.com/jotalanusse/soular).

- `master` is an unmodified copy of upstream's `master`, synced daily by `.github/workflows/sync.yml` on this branch.
- `sync` (the default branch) holds only the sync workflow and this file, so `master` never diverges from upstream.
